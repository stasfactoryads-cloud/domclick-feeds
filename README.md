# Фиды Домклик ГК «ПСК»

Генератор XML-фидов для площадки Домклик (новостройки).

- ЖК «Акватория» (ID 44), ЖК «Ассамблея» (ID 41).
- Данные о проектах и планировках берутся из API сайта psk-info.ru.

Запуск:

```bash
python3 generate_domklik_feed.py
```

Фиды сохраняются рядом со скриптом. Структура XML требует сверки со спецификацией Домклик.
